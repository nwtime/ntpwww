The following documents are works-in-progress for various proposals the NTP Project expects to add to the IETF's NTP specification.  If the WG wants these features in the full NTP Standard, these proposals will be submitted on the Standards Track.  If the WG is not interested in these features, they will be submitted on the Informational Track.

* [Network Time Protocol Extended Information Extension Field](/documentation/ietf/ntp-extended-information-ef/)
* [Network Time Protocol Version 4 (NTPv4) Extension Fields](/documentation/ietf/ntp-extension-fields/)
* [Network Time Protocol I-Do Extension Field](/documentation/ietf/ntp-i-do/)
* [Network Time Protocol Leap Smear REFID](/documentation/ietf/ntp-leap-smear-refid/)
* [Network Time Protocol MAC/Last Extension Fields](/documentation/ietf/ntp-mac-last-ef/)
* [Network Time Protocol REFID Updates](/documentation/ietf/ntp-refid-updates/)
* [Network Time Protocol: Secure Network Time](/documentation/ietf/ntp-secure-network-time/)
* [Network Time Protocol Suggested REFID Extension Field](/documentation/ietf/ntp-suggest-refid/)
* [Network Time Protocol: TCP Services: Key Exchange](/documentation/ietf/ntp-tcp-services-keyexchange/)
* [Network Time Protocol: TCP Services](/documentation/ietf/ntp-tcp-services/)
